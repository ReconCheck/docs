# ReconCheck docs

Documentation for [ReconCheck](https://github.com/ReconCheck/core) — the cross-document verification engine.

> **Status: not started.** The engine is still being built. This repository is a placeholder so the URL is reserved.

## Planned contents

- **Getting started** — install, first run, first pair of documents
- **Document formats** — how parsing handles scans, borderless tables, multi-column PDFs, and where it gives up
- **Alignment** — entity resolution and unit normalisation, and how to override both
- **Writing rules** — the differential rule format, with worked examples
- **Integration** — feeding results into an ERP, and why the engine stays read-only
- **Deployment** — on-premise installation, network isolation, resource sizing

## Contributing to the docs

Corrections and additions are welcome once the engine has a stable interface.
Until then, please raise an issue rather than a pull request.
